# Wireshark Packet Analysis
Wireshark를 활용해 실제 호스트 환경에서 수집한 네트워크 패킷을 분석하고, 프로토콜 동작 원리 및 트러블슈팅 과정을 기록하는 공간입니다.

---
## 🦈 주요 실습 목표
- **패킷 레벨 트래픽 분석**: L2(ARP)부터 L4(TCP/UDP), L7(DNS/TLS/HTTP)까지 각 계층별 프로토콜 흐름 검증
- **트러블슈팅 및 노이즈 제어**: 백그라운드 트래픽 제어, Display Filter 활용, 세션 연결/종료 패턴 분석
- **실무 분석 역량 향상**: 캡처 파일 내 패킷 추적 및 장애 원인 식별

※ 본 저장소에는 개인정보, 세션 토큰 및 실제 IP 보호를 위해 `.pcapng` 원본 파일 대신 **마크다운 정리본**만 작성하였습니다.
